Import / export

Only local JSON is processed. Imported data is stored in browser localStorage and is never uploaded; it remains available after a refresh.

Live AI (off by default)

The public copy stores no API key in the browser. A compatible endpoint configured by the operator is called only after explicit server-side opt-in; the local rule engine remains the default.

Security boundaries

  • No third-party map tiles, search APIs, or telemetry requests.
  • The server listens only on 127.0.0.1 and is not exposed to the internet.
  • Logs omit request bodies, query strings, and credentials.
  • Imports are validated for fields, length, numeric ranges, and HTML characters.
  • The page uses a strict CSP and loads no external scripts or styles.

Import format

Accepts one district object or a { "district": { ... } } wrapper. Up to 50 stores with coordinates within ±3 km.

{
  "district": {
    "id": "demo-district",
    "name": "Demo District",
    "shortName": "Demo",
    "description": "A fictional district for local testing.",
    "center": { "x": 0, "y": 0 },
    "coverageRadiusKm": 3,
    "stores": [
      {
        "role": "focus",
        "brand": "Northstar Tea",
        "name": "Northstar Tea · Demo One",
        "x": 0.4,
        "y": -0.2,
