安全边界

  • 无第三方地图底图、搜索接口或遥测请求。
  • 服务只监听 127.0.0.1，不对外网开放。
  • 日志不记录请求体、查询字符串或凭证。
  • 导入内容做字段、长度、数值范围与 HTML 字符校验。
  • 页面使用严格 CSP，不加载外部脚本或样式。

导入格式

支持单个商圈对象，或 { "district": { ... } } 包装。最多 50 家门店，坐标范围 ±3 km。

{
  "district": {
    "id": "demo-district",
    "name": "Demo District",
    "shortName": "Demo",
    "description": "A fictional district for local testing.",
    "center": { "x": 0, "y": 0 },
    "coverageRadiusKm": 3,
    "stores": [
      {
        "role": "focus",
        "brand": "Northstar Tea",
        "name": "Northstar Tea · Demo One",
        "x": 0.4,
        "y": -0.2,
        "address": "Unit 12, Demo Walk (fictional)",
        "monthlyOrders": 640,
        "channels": {
          "Marketplace A": {
            "deliveryFee": 2.5,
            "promotionPct": 16,
            "promotionLabel": "Spend 25 save 4",
            "couponValue": 3
          },
          "Marketplace B": {
            "deliveryFee": 2.0,
            "promotionPct": 12,
            "promotionLabel": "Spend 25 save 3",
            "couponValue": 2
          }
        }
      }
    ]
  }
}
